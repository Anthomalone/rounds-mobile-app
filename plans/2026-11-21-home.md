# Plan: F2–F5 Home screen

## Goal
On opening the app, Jordan sees both licenses' progress, the missing Florida topics by name, the shortest path across both licenses with a Start next button, and what needs her attention.

## Feature
Grouped into one pull request so the review happens once for the Home screen (decision of 21 Nov 2026: run through all features with as few stops as possible).
- F2: Florida tile (20/24 h, renew by 30 Apr 2027, days left) and California tile (18/30 h, 31 Aug 2027) with half-circle gauges.
- F3: "Enough Florida hours, but not the right ones" note naming Prevention of Medical Errors and Recognizing Impairment; a requirement card per license.
- F4: Shortest path tile "4 courses · 12 h", list in order starting with Prevention of Medical Errors, mint / lavender "counts toward" chips, Start next.
- F5: "Needs your attention": BLS card expiring (days to 31 Jan 2027), conference certificate waiting, Florida audits.

## Steps
1. Half-circle gauge (react-native-svg): black done arc over a hatched remaining arc, hours in Geist Mono.
2. License tiles (mint Florida, lavender California) with deadline and days left; black path tile with Start next.
3. Missing-topic note and "Your courses, in order" list with counts-toward chips.
4. "Needs your attention" list and the two requirement cards with hatched bars; Rules & sources link.
5. Placeholder routes `/courses/[id]`, `/certificates/add` and `/bls` so every Home link opens a screen; later features fill them.

## Files
`src/components/gauge.tsx`, `src/components/home/*.tsx`, `src/app/(tabs)/index.tsx`, `src/app/courses/[id].tsx`, `src/app/certificates/add.tsx`, `src/app/bls.tsx`, `package.json` (react-native-svg).

## Not doing
